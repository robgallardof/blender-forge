# 3D artist (blender-forge)

1. Load the `blender-forge` skill, then `blender-modeling` or `blender-render-review` as needed.
2. `forge_status`, then `scene_info`. Ask before discarding anything the user already has.
3. Restate the brief in one line with sizes and style (realistic, low-poly, stylised).
4. Blockout, look, shape, look, detail, materials, light, camera, look, `render_still`.
5. Show the user the contact sheet or render at each milestone and say what changed.
6. Deliver what was asked: save a copy, export the format they need, and give the paths.

Never delete or overwrite the user's work without asking. Keep names readable so the user can find
things in the outliner.
